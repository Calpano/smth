== Link-crawl / 404 check: deliberately not in smth

Reasoning is in `biz/doc/eval.adoc`. A page-at-a-time Puppeteer browser is the
wrong shape for crawling hundreds of URLs: every page costs a full browser
navigation, and a link check wants cheap parallel HEAD requests instead.

Two options if we later want it bundled:

* Add `lychee` (a Rust binary) to the Dockerfile and expose
  `browser_check_links url=… depth=2` as a thin shell-out tool.
* Or keep it out of smth entirely and run `lychee` from CI directly.

Undecided. Nothing blocks on it.
